## 紹介

🏠 現代的でインタラクティブ、モジュール化された技術を用いて、簡単に情報を記入するだけで不動産や住宅紹介ウェブサイトページを構築できる 🏠

## 使用技術

- React v19.x
- Next v15.x
- TailwindCSS v4.x
- Aceternity UI コンポーネント
- Shadcn UI
- Motion
- Resend メールインターフェース
- ES6+ 文法およびESMを用いたTypescript

## 特徴

- [x] ミニマルなスタイリング
- [x] React v19およびNext v15と互換性あり
- [x] レスポンシブレイアウト
- [x] フレンドリーなSEO
- [x] ダークモード
- [x] 高品質なUIエフェクト
- [x] Resendで構築されたメールテンプレート

## 実行要件

- NodeJS LTS 22以上

## インストール

### リポジトリをクローン - 推奨

まず、以下のコマンドを実行してこのリポジトリをローカルにクローンします。

```sh
$ git clone https://github.com/gaomingzhao666/estate-website.git # クローン
$ cd estate-website
```

クローンがエラーなしで完了したら、次のコマンドを実行して依存関係をインストールし、プロジェクトを起動します。

```sh
$ pnpm install
$ pnpm dev
```
